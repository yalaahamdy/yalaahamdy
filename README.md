This repository also powers the **Yalaah Apps Distribution Hub** built with Next.js 16, TypeScript, and Tailwind CSS.

### Running Locally

```bash
# Install dependencies
npm ci

# Start development server
npm run dev

# Run full tests & lint
npm test
npm run lint
npm run typecheck

# Build static export
npm run build
```

### Adding a New App to the Hub

1. Edit [`data/apps.json`](data/apps.json) and add your app's configuration.
2. Commit and push to `main` — GitHub Actions builds and deploys the updates automatically!
